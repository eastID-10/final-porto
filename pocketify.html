Pocketify Mobile App

A mobile app concept with a gamification layer, designed in Figma from system flows to custom icons, then built as a React Native front end.

Role
UI/UX Designer and Mobile Developer
Timeline
Feb 2025 – Jun 2025
Type
Mobile app, course project
Tools
Figma, Draw.io, React Native

Planning

Application logic and system flows defined through use case, activity and ERD diagrams.

Design

Complete UI/UX in Figma, with custom icons and visual assets aligned to the gamification concept.

Feature

Currency recognition using a MobileNetV2 model that predicts money value from camera input.

01

Concept and system flows

I defined the application logic and the system flows through use case, activity and ERD diagrams, together with the app concept.

02

Visual design

The complete UI/UX was designed in Figma, from low-fidelity layouts to high-fidelity screens. I drew custom icons and curated visual assets so the look supports the gamification concept.

03

From design to code

I implemented the finalized design as a mobile front end in React Native, coordinating design and development decisions along the way.

04

Camera-based currency recognition

The app integrates a MobileNetV2 machine learning model that detects and predicts money value from camera input, which gave the interface a camera flow to design around.
